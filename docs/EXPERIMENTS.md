# 三种子验证协议

- 种子：1、2、3；筛选实验的种子 0 不进入正式统计。
- 数据：固定的 40 条 G1 LAFAN1 CSV，SHA-256 见 `reproducibility/data_sha256.json`。
- 每个种子运行 baseline、root_position、torso_position，共 9 次全新训练。
- 每次 6,000 迭代，5,500 次 actor 更新，30,000 次世界模型梯度更新，61,702,144 次真实仿真转移。
- 4,096 并行环境；学习率 4e-4，衰减跨度固定为 250,000；世界模型 1024×1024×1024，5 次 WM batch；EMA 0.995，contact reward 0.25。
- 评测初始、2,000、4,000、6,000 迭代检查点；同一种子内核对共同参数和 CPU/CUDA RNG，不同种子使用不同初始化。
- 三种方案轮换使用三张 RTX 3090。温度保护造成不同暂停时间，因此本实验按更新数比较，不据此声称训练速度提升。

预设验收为每个种子都满足：40/40 动作完成、水平误差比基线至少降低 20%、关节 RMSE 比值不超过 1.05。根节点方案三个种子全部通过；躯干方案仅一个种子通过，另外两个种子各有一条动作未完成。

## 指标与覆盖

原始 CSV 为 30 Hz，参考以 float64 线性插值位置和关节角、四元数 SLERP 重采样至 50 Hz。用记录的逐步参考帧 ID 配对仿真状态，不做平移、旋转或时间配准。位置指标使用世界坐标，关节 RMSE 按全部关节和配对帧计算。

`results/three_seed/summary.json` 保留全部 36 个评测点及各方案的实际有效帧统计。失败会缩短可用轨迹，不能把短前缀的误差直接当作完整动作成绩。

为公平比较，`endpoint_independent_audit.json` 在每个种子内截取三种方案共有的相同帧。README 的位置和关节结果来自这些相同帧；完成动作数仍按完整评测单独报告。`identical_prefix_summary.json` 是这些指标的跨种子均值和样本标准差，`tools/report_results.py --check` 可独立复算。

三个种子足以检查本轮改动的一致性，本报告不作统计显著性或未见动作泛化声明。所有评测动作都属于训练动作。独立审计通过且训练源码校验值未发生变化。

## Loss

`results/three_seed/training_logs/` 保存每个种子和方案的原生训练 CSV。包含世界模型 loss、策略 loss、critic loss 与训练回报。前 500 次迭代只训练世界模型，绘图时会把这段与策略优化区分。Loss 用于观察训练过程，最终表现依据物理轨迹误差与完成率判断。

源码发布时只整理配置和工具，没有再次运行这 9 组训练。发布工具的验证记录单独保存在 `reproducibility/release_validation.json`。
