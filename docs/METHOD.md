# 根节点位置反馈

在原策略观测末尾追加三个通道：

```text
e_position = R_robotᵀ · (p_reference − p_robot)
```

`p` 的单位为米；`R_robot` 是当前机器人根节点的完整旋转矩阵。该误差表达在当前根节点坐标系中，包含水平和竖直方向。

G1 原观测为 99 维，根节点方案为 102 维；10 帧历史对应的策略解码器输入随之扩展。新连接初始化为零，原有连接、critic 初始化和随机数状态保持一致，因此各方案初始动作一致。三个种子的共同初始化均已检查。

新增位置通道在本实验中不加噪声。原有通道的噪声采样维度和随机数消费保持原样，避免额外随机数改变对照。可微世界模型的状态和预测目标、奖励、重置采样与训练更新预算沿用实验配置。

检查点记录 `args.position_obs`。缺失这个字段的旧检查点按 `none` 加载；`root`、`torso` 的归一化观测长度为 102。评测与导出应依据检查点元数据构造模型，不能仅根据当前训练默认值推断。

输入来自仿真真值；使用实机或带定位误差的感知输入时，需要额外验证误差、延迟和坐标系一致性。当前根节点实现只支持无状态 sensing 配置，代码会拒绝不兼容的有状态 sensing 设置。
